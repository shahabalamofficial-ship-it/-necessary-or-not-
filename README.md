# Necessary or Not? 🌿

A quiet, philosophy-inspired reflection tool for slowing down before you act.

## ✨ Updates

- English / Urdu language toggle (EN / اردو)
- Full bilingual interface, reflection questions, results, categories, history and helpful messages
- Friendly emojis and warmer microcopy
- Psychology-informed reflection prompts around urgency, pressure, autonomy, attention and future-self thinking
- Philosophical framing inspired by Stoic reflection
- Mobile/iPhone-friendly responsive design
- Local browser history remains on the user's device
- Still a single static `index.html` with no build step

## GitHub Pages

Upload `index.html` and `README.md` to the root of your repository, then enable GitHub Pages from the repository's Pages settings.

No Node.js, npm, database, API key or build process is required.

## Privacy

Reflections are stored locally in the browser using `localStorage`. The app does not send reflection data to a server.
